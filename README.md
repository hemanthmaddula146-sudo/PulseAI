## 📌 Overview

**PulseAI** is an AI-powered disaster intelligence platform that brings earthquake information, natural-event tracking, interactive mapping, and AI-generated safety guidance together in one modern dashboard.

Built using Next.js, TypeScript, public disaster data sources, and Google Gemini, PulseAI helps users explore disaster-related information through a unified and accessible interface.

### 🎯 Mission

Make disaster information easier to explore and understand by combining real-time data sources, interactive visualization, and AI-powered assistance.

## ✨ Key Features

| Feature | Description |
|---|---|
| 📊 **Intelligence Dashboard** | View a consolidated overview of disaster-related information. |
| 🌎 **Earthquake Monitoring** | Explore earthquake information from USGS data services. |
| 🌪️ **Natural Event Tracking** | Discover natural events provided by NASA EONET. |
| 🗺️ **Interactive Map** | Explore geographic event information visually. |
| 🤖 **AI Assistant** | Ask disaster-related questions and receive AI-generated explanations and general safety guidance. |
| 🚨 **Alerts** | Access the application's disaster-related alert information. |
| 🌦️ **Weather** | Visit the weather information page. |
| 📑 **Reports** | Access the application's reports section. |
| ⚙️ **Settings** | Access application settings and preferences. |
